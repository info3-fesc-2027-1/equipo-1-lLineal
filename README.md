## Contexto y objetivo

El taller mecánico llevaba el control de sus pedidos de forma manual, lo que dificultaba saber en qué etapa estaba cada reparación. Este proyecto lo sustituye por una plataforma web centralizada que permite:

- Registrar a los clientes del taller.
- Consultar el catálogo de productos y servicios.
- Crear pedidos con su total calculado automáticamente.
- Dar seguimiento al estado de cada pedido, desde que se registra hasta que se entrega.
- Consultar el listado de pedidos con rapidez.
